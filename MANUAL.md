# LeadItNow user manual

## Check a company for need signals

1. Open LeadItNow and type the company's website domain, for example `acme.co.in`.
2. Select **Scan for need signals**. The scan takes up to a minute.
3. Read the result:
   - **High** (40 or more): clear signs the business needs new software or services. Call first.
   - **Medium** (20-39): some signs; research the brief before calling.
   - **Low** (under 20): weak signs; nurture rather than call.
   - **None**: no public need signals. Add a referral, job post or growth news if you know one.
4. **Lead with** suggests which service line to open the conversation with (for example e-commerce or ERP).
5. **Current stack** lists the tools the business already uses. It is for the Business Analyst's planning only: never mention another vendor in outreach.
6. Each need signal shows its evidence: the page or DNS record where it was found.

LeadItNow only reads public DNS records and public web pages. It never logs in anywhere.
