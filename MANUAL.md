# LeadItNow user manual

## Check a company for Zoho signals

1. Open LeadItNow and type the company's website domain, for example `acme.co.in`.
2. Select **Scan for Zoho signals**. The scan takes up to a minute.
3. Read the result:
   - **Confirmed** (40 or more, with at least one verified signal): the company almost certainly uses Zoho.
   - **Likely** (20-39): probably uses Zoho; confirm on the first call.
   - **Possible** (under 20): a weak trace; research before calling.
   - **None**: no public Zoho traces found. They may still use Zoho internally.
4. Each signal shows its evidence: the DNS record or the page where it was found. Signals marked *(to confirm)* use patterns we are still validating.
5. "Already customising Zoho" means a Zoho Creator app or a Zoho developer job post was found. Call these first.

LeadItNow only reads public DNS records and public web pages. It never logs in anywhere.
